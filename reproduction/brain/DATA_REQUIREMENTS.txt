The transfer_dir setting points to the directory containing inputs/ and
FRESH_REQUEST/. Preserve that structure. These are preprocessed R objects, not
arbitrary expression matrices. The original engines explicitly verify study
identity and reject replacement files. MD5 is used for file identity, not security.

The preparation engine derives direct donor mixtures and corresponding true
cell-type components from these objects and validates donor separation and panel
alignment. Raw-reference input includes 39,692 nuclei for the reference donors.
See engines/direct.R for the exact schema checks and aggregation implementation.

Generate these inputs from the downloaded AD/Aging Brain Atlas objects using
preprocessing/run.R; see preprocessing/README.md for exact commands and files.
The original MD5 values above identify archived serializations. Regenerated files
may have different bytes and are accepted only if their numerical signatures
match preprocessing/expected_content.csv. Data, donor ordering, reference nuclei,
counts and inference settings remain fixed. No mismatched input is accepted.

The wrapper/output contract has been tested using archived numerical inputs and
mutation checks. Full raw-data clustering and reconstruction have not been rerun.
Downloaded data and generated RDS objects are not included in this repository.
