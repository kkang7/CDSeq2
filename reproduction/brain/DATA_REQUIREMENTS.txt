The transfer_dir setting points to the directory containing inputs/ and
FRESH_REQUEST/. Preserve that structure. These are preprocessed R objects, not
arbitrary expression matrices. The original engines explicitly verify study
identity and reject replacement files. MD5 is used for file identity, not security.

The preparation engine derives direct donor mixtures and corresponding true
cell-type components from these objects and validates donor separation and panel
alignment. Raw-reference input includes 39,692 nuclei for the reference donors.
See engines/direct.R for the exact schema checks and aggregation implementation.

An external reader needs approved access to the underlying ROSMAP resources and
the exact prepared objects, or a separately released preprocessing workflow that
creates them. This bundle does not fill that upstream data-access/preprocessing
gap. Do not describe it as a public one-command reproduction until this is resolved.
For an unrestricted demonstration, release a separate synthetic/toy dataset and
example workflow; the current study-specific engines intentionally reject it.
